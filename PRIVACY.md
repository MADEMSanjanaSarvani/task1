# Privacy Policy

This project ("Hustle Signal") is a personal, automated content pipeline that
generates and publishes content, including YouTube Shorts, to a single
YouTube channel owned by the developer.

## What this app does

- Runs on a schedule via GitHub Actions to research trends, generate content,
  and publish videos to one YouTube channel controlled by the developer.
- Uses the YouTube Data API solely to upload videos and set metadata
  (title, description, thumbnail) on that one channel.

## Data collection

This app does not collect, store, or share personal data from any third
party or end user. It does not have external users signing in — the only
Google account involved is the developer's own account, authorizing the
app to upload to their own YouTube channel.

No data obtained through the Google APIs is shared with any third party,
sold, or used for advertising purposes.

## Data retention

Any tokens or credentials used are stored as encrypted secrets in the
project's GitHub Actions configuration and are not accessible to anyone
other than the repository owner.
